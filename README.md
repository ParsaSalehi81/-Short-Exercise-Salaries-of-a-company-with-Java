# Worker Salary Management

Simple Java program for managing workers and their salaries.

For each worker, the program stores their name, base salary and complement. It calculates their total salary and also the total salary of all workers in the company.

Workers are stored in an `ArrayList`, so the program can handle different numbers of workers without needing to fill 100 fixed spaces.

The salary calculation is kept in a separate method so it can be changed later, for example to include taxes.
